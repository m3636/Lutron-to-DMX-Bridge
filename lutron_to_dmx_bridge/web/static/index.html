Schedule sets

A set holds some schedules off (and optionally others on) with one button, for example Performance mode. Activating remembers each schedule's current on/off state; restoring puts back exactly that, so schedules that were already disabled stay disabled. Nothing is deleted or edited in the Lutron system.

Schedules

Schedules (timeclock events) come from the Lutron system. This app can only enable or disable them — they are never deleted or edited, so disabling is always reversible.

This system reports no schedules (or the active driver can't read them).

DMX input

Let a lighting console drive Lutron zones. Each mapped zone listens to one or more consecutive DMX channels. Lutron systems are slow compared to DMX, so changes are rate-limited per zone.

    Settings

    Lutron system

    The simulator pretends to be a small house so you can try the app without any hardware. Nothing is sent to real lights.

    RadioRA 2 talks to the Main Repeater over your LAN using the Lutron integration protocol (telnet, port 23).

    1. Give the Main Repeater a fixed IP (or DHCP reservation) and enter it below.
    2. In RadioRA 2 Essentials/Inclusive software, add an integration login (Settings → Integration → Telnet logins) and transfer to the system. Enter that user name and password here.
    3. Optional: point to the Integration Report so zones, areas and keypads have names. It can be saved from http://<repeater-ip>/DbXmlInfo.xml or exported from the software. Without it, zones may show up with numeric integration IDs instead of names.

    RadioRA 3, RA2 Select and Caseta use LEAP, a secure (TLS) local protocol. The app must be paired once with the processor/bridge to get a certificate.

    1. Enter the processor / bridge IP address below.
    2. Press Pair, then within about 3 minutes press the small pairing button on the back of the processor or bridge (on RA3 processors and Smart Bridges it's the button on the back; Caseta: press once, quickly).
    3. When pairing succeeds the certificate folder is filled in automatically. Press Save & reconnect.

    Updates

    Lutron To DMX Bridge runs entirely on your own network. The one exception is this: it asks GitHub whether a newer release exists (a single request for the public release information, on start-up and every 12 hours) and sends nothing about you or your lights. Turn automatic checks off below and the app only contacts GitHub when you press Check now. An update is only ever installed when you click Update now; your settings and scenes are not touched, and the previous version is kept.

    Backup

    Downloads everything the app can read from the Lutron system (zones, areas, keypads, schedules, levels) plus this app's scenes and DMX settings, as JSON. A copy is also kept in the app's data folder under backups/.
